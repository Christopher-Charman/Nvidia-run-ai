  • Pool

  • Autoscaling
  • The Gateway

Standalone open source. Run:ai is one pod owner among many.

Grow later

5 · Later 🔜

Then, in order

#AddSo that
1Ownership modeswhen Dynamo or KServe already own the pool, we add only the route
2Smart EPP, llm-d Routerthe picker uses KV cache and prefix hits, not just queue length
3Enforced lanesgold traffic really goes first, batch really waits or is dropped
4Validated canary10 % to the new model, checked against what the pods actually serve
5More gatewaysIstio, Envoy AI Gateway, NGINX, not only agentgateway
