# GitHub Pages branch

This branch is the website GitHub Pages serves for this repository at
https://dsx-ai-factory.github.io/run-ai/. Each site lives in its own folder.

- `flowmark/`: the FlowMark nightly benchmark dashboard. `index.html`, `app.js`
  and `styles.css` are copied here from `scale-load/flowmark/dashboard` on
  `main` by the publish workflow; `manifest.json` and `results-*.json` are
  written by the nightly workflow in run-ai/runai-e2e-internal.

Nothing on this branch is edited by hand, and it is never merged anywhere.
