# FlowMark results

Published output of the FlowMark nightly benchmark. Served by GitHub Pages at
https://dsx-ai-factory.github.io/run-ai/.

- `manifest.json` and `results-*.json` are written by the nightly workflow in
  run-ai/runai-e2e-internal after every scheduled run.
- The dashboard files are copied from `scale-load/flowmark/dashboard` on `main`.

Nothing on this branch is edited by hand, and it is never merged anywhere.
