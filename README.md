# GitHub Pages branch

The website GitHub Pages serves for this repository at
https://dsx-ai-factory.github.io/run-ai/. Each site lives in its own folder.

- `flowmark/`: the FlowMark nightly benchmark dashboard.
  `manifest.json` and `results-*.json` are the published nightly results;
  the dashboard files are copied from `scale-load/flowmark/dashboard` on `main`.
